## 总原则
- 一切决策 = 同一笔账：`EV = Σ 路线 P(在剩余摸牌内走完且别家没先胡) × 番 × 收入 − P(别家先自摸) × 付出`，选最大。
- 每一项都挂独立开关（`mj/fit.py` 默认权重，默认 0），开关全关时行为与现在逐张一致；任何异常吞掉回落原逻辑。
- **单次决策耗时预算**：新增逻辑合计超过 `rev_time_budget_ms`（默认 150）立即放弃并回落原逻辑（计时用 `time.perf_counter`）。
- 验收只看我们自己的实战结果（速度、胜率、番数、得分），不以"像不像高手"为准。

## P1 输钱项 + 差值门槛（开关 `rev_loss_enabled`）
- `_win_probability` 同时返回 `win` 和 `lost`（别家先自摸的概率质量），守恒写测试。
- 路线价值 `win×fan×payout − lost×loss`；`loss` 取 `rollout_cal.json` 的 `|pay_d|/|pay_n|`，缺省权重 `rev_loss_dealer=10.33`、`rev_loss_idle=4.73`。
- 所有"是否改写/否决"的比较改为差值门槛：`新 − 旧 ≥ max(rev_margin_abs, rev_margin×|旧|)`，`rev_margin_abs` 默认 0.5。

## P2 速度前瞻（开关 `rev_speed_enabled`）——全部手牌，不限门清/财神
- 适用：chain=0、piao=0、非抓打圈、原逻辑同向听层 `tier` 的向听 ≤ 1（即选"一向听怎么打"和"听牌听什么"）。**只在 tier 内换牌，绝不改变向听。**
- 前瞻（新函数，放 `mj/route_ev.py`）：
  - 听牌（向听 0）：`w` = 听口活牌数（按 `visible` 扣已见）；爆头听 `w` = 未见牌总数。
  - 一向听：对每张有效牌 t（活牌数 n_t>0）模拟摸入 → 在保持听牌的弃牌里选听口活牌数最大的 → 得 W_t；
    `p = Σn_t / U`，听牌后的 `q = (Σ n_t·W_t / Σ n_t) / U`；若某个 t 摸入后能打成爆头听，W_t = U（摸啥都胡），番按 2。
  - 用 `_win_probability`（含 P1 输钱项）算每个候选的 EV，选最大；与原逻辑选择的差达到差值门槛才改写。
- 剪枝：tier 内先按一步活牌数排序，只对前 `rev_speed_topk`（默认 4）个候选做前瞻；超预算回落。
- 接入：两个弃牌入口（`mj/strategy.py::choose_discard`、`mj/ev.py::choose_route_discard`），放在现有 route EV 叠加之后、原逻辑之前；
  庄闲都适用（庄家 payout 24、loss 10.33）。

## P3 标准爆头参与改写 + 离爆头一步的前瞻（开关 `rev_override_b_enabled`）
- 门清持财神范围内，最优路线为 B 时也允许改写弃牌/否决吃碰（差值门槛）。
- B 路线距离 1 时 `p` 用 `baotou_waits` 活牌数（已有），距离 0 时 `q=1`；距离 2 用 P2 的一向听前瞻思路近似（有效牌摸入后 `baotou_waits` 活牌数的加权平均）。
- 预筛：候选里存在 `to_baotou_distance ≤ 2` 才算完整账（与 `_pair_rich` 并列）。

## P4 财飘 / 胡牌 按账决策（开关 `rev_piao_enabled`、`rev_decline_enabled`）
- `mj/hu_strategy.py::choose_hu_or_piao`：
  - 可飘（`_piao_candidate` 返回财神，硬条件不变：飘后仍爆头、chain+piao<3、剩余可摸 ≥ 1 轮）时，比较
    `当场胡 = f×payout` 与 `飘 = 2f×payout×s − (1−s)×loss`，`s` = 本家下一次摸牌前别家都没自摸的概率（hazard 表，同 route_ev）。
    飘了以后下一摸仍是同样的判断（逐步决策，自然形成连飘）。开关打开时替代现有 `chain_rate / high_fan_force / success_floor`
    阈值逻辑；关闭时完全不变。
  - 非爆头可胡、存在打一张成爆头（含七对·爆头）时（S1），比较 `当场胡 = f×payout` 与
    `转爆头 = P(剩余摸牌内摸到 且别家没先胡)×2f×payout − lost×loss`（爆头态每摸必胡，P 由 hazard 逐轮连乘），取大；
    开关打开时替代现有财神数×副露格子与「剩余 <8 张」闸门；弃哪张仍用 `_decline_discard_choice`。
- 财神保留：P2/P3 的账里，持 2+ 财神、爆头听的手，额外计入「飘一次」的期望增益（用上面同一公式），使弃牌时倾向保留能飘的第二张财神。

## P5 吃碰按账（开关 `rev_claim_enabled`，最后做）
