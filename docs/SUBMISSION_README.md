# 乾元用九 · 杭州麻将 AI 程序使用说明

## 1. 运行环境

- Python 3.9 及以上，**只用标准库**，不需要安装任何第三方包，也不需要编译。
- 操作系统不限（macOS / Linux / Windows 均可）。
- 单进程运行。本地决策耗时：实测 p99 约 150ms，最大约 0.5s，在出牌 3 秒、吃碰 1 秒的时限内。

## 2. 目录结构

| 路径 | 内容 |
|---|---|
| `mj/` | 全部源码。入口是 `mj/bot.py` |
| `models/*.json` | 策略参数：打分权重、庄家价值表、对手听牌速度表等。程序启动时读取 |
| `logs/` | 运行日志（jsonl），首次运行时自动创建 |

## 3. 接入平台

令牌通过环境变量 `MJ_TOKEN` 传入，不要写进命令行或代码。

服务端地址用 `--server` 指定，默认是 `https://10.240.169.190:18080`。地址不同时，在命令里加上 `--server <地址>`。

## 4. 启动

在本目录（含 `mj/` 的目录）下执行。

**正式赛（多阶段全自动）：**

```bash
MJ_TOKEN='<AI 身份令牌>' python3 -m mj.bot --wait
```

- 自动完成报名确认、每个阶段的出席确认（ready）、对局、阶段之间的等待。
- 赛事进入终态（finished / closed / void）后正常退出。
- 请在开赛前启动，并且全程保持运行。

**自由匹配（调试用）：**

```bash
MJ_TOKEN='<令牌>' python3 -m mj.bot --once
```

打完一个房间就退出。不带 `--once` 会一直匹配下去，按 Ctrl+C 停止。

**查看全部参数：**

```bash
python3 -m mj.bot --help
```

## 5. 策略概要

- **出牌：** 先按向听数分层，同一层内用拟合过的特征打分选牌。门清并且手里有财神时，比较平胡、爆头、七对等几条路线的期望得分。
- **胡、飘、弃胡：** 能胡默认就胡。手里有财神、可以转成爆头时，按期望得分决定是否先不胡，改冲爆头；手里有 2 张以上财神、牌墙还早（剩 54 张以上）且副露不超过 1 组时，即使还差一步才能转成爆头，也会先不胡；财飘按期望值决定。
- **吃、碰、杠：** 只在能改善手牌时才吃碰。七对路线下不吃碰。杠受门槛约束，墙尾不杠。
- **容错：** 全部动作在本地按快照判定合法后才提交。网络异常时会重新拉取完整快照并自动重试。
