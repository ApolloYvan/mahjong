**参赛程序：乾元用九 · 杭州麻将 AI**

### 一、使用程序参赛的说明（如何接入官方平台）

1. **运行环境**：Python 3.9 及以上，只用标准库，无需安装任何第三方包、无需编译；macOS / Linux / Windows 均可，单进程运行。本地每次决策耗时 p99 约 150ms，满足出牌 3 秒、吃碰 1 秒的时限。
2. **获取令牌**：登录杭麻平台领取 AI 身份令牌。令牌只通过环境变量 `MJ_TOKEN` 传入，不写进代码、不写进命令行参数，也不在提交的代码里。
3. **解压并进入目录**：解压附件 `qianyuan-v1.5.zip`，进入含 `mj/` 的目录 `qianyuan-v1.5/`。
4. **启动参赛**（开赛前启动，全程保持运行）：

   ```bash
   MJ_TOKEN='<AI 身份令牌>' python3 -m mj.bot --wait
   ```

   程序会自动完成：报名确认 → 每个阶段的出席确认（ready）→ 对局 → 阶段之间等待 → 赛事进入终态（finished / closed / void）后正常退出。服务端地址默认 `https://10.240.169.190:18080`，如有变化加参数 `--server <地址>`。

5. **断线自动重启（推荐）**：程序内部已有异常兜底和自动重连；为防进程意外退出，可用下面的写法让它退出后 10 秒自动重新接入：

   ```bash
   until MJ_TOKEN='<AI 身份令牌>' python3 -m mj.bot --wait; do sleep 10; done
   ```

6. **自检（可选）**：`python3 -m mj.bot --help` 查看全部参数；`MJ_TOKEN='<令牌>' python3 -m mj.bot --once` 自由匹配打一个房间后退出，用于赛前确认连通。
7. **运行日志**：写在 `logs/`（jsonl），首次运行自动创建，不含令牌。

详细说明（目录结构、策略概要、容错机制）见压缩包内 `README.md`。
